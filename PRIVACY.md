# Privacy and data flow

The browser attempts to remove selected identifiers and URL paths, queries, fragments and credentials. This is best-effort matching, not anonymization. Names, addresses, unusual identifiers, URL hosts and other sensitive content may remain. The user can edit and must confirm the preview before sending. A direct API caller can send raw input; the server also sanitizes it, but this does not prevent transmission to the server.

The application has no message database and does not deliberately log request text. A hosting provider or intermediary may retain technical data; review its actual configuration before deployment. If AI is requested, consented to and enabled by the operator, the server sends the remaining sanitized text to the configured OpenAI-compatible endpoint, including URL hosts. That endpoint may relay to another model provider. `store: false` is sent, but endpoint and upstream retention and processing depend on applicable terms and settings; this is not a zero-retention guarantee. No claim of GDPR compliance is made without an appropriate assessment.

Optional PostHog EU analytics requires a separate browser choice; consent to AI does not enable analytics. When enabled by the operator and accepted by the visitor, the browser sends named page categories and limited business outcomes. Server telemetry for an opted-in visitor adds AI status, failure category, duration, token counts and estimated USD cost. Events use an app-scoped random ID, `app=overto_ai`, an environment label and schema version. Event projection strips message text, email, URL query/fragment, prompt and response content. Autocapture, session replay, feature flags and automatic exception capture are disabled. Browser/runtime errors are reported only as generic categories, without raw stack or message. Declining or withdrawing consent stops optional capture; the preference is stored in a first-party cookie. The hosting operator must configure PostHog retention and legal basis for its deployment. See [the observability guide](docs/observability/posthog.md).
