# OvěřTo.AI

Experimentální český pomocník pro posouzení podezřelých zpráv a nezávislé ověření. Neověřuje totožnost odesílatele, neotevírá odkaz a nezaručuje bezpečí.

Prohlížeč se pokusí zakrýt některé údaje; před odesláním text sami zkontrolujte. Pravidla fungují bez modelu. Volitelná integrace OpenLux vyžaduje souhlas uživatele i konfiguraci provozovatele; zatím nebyla ověřena živým voláním. Při nedostupnosti se zobrazí pouze výsledek pravidel. Testovací sada je syntetická, nikoli nezávislé měření účinnosti.

Instalace a příkazy jsou v [README.md](README.md). Podrobnosti: [soukromí](PRIVACY.md), [bezpečnost](SECURITY.md) a [evaluace](docs/evaluation/ai-evaluation.md). Projekt dosud není veřejně nasazen ani připraven na neomezený veřejný provoz.
