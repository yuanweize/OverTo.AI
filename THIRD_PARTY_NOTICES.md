# Third-party components

Dependencies are installed separately from the npm registry and retain their own licenses; the Apache-2.0 project license does not relicense them. Consult `package-lock.json` and the license files distributed with each package. Notable transitive packages include the MIT-licensed `tldts`, optional LGPL-3.0-or-later `@img/sharp-libvips-*` binaries, and CC-BY-4.0 `caniuse-lite` data. Distribution of binaries or modified components can carry additional obligations and requires its own license review. The source repository does not vendor `node_modules`.
