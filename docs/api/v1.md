# Analysis API v1 (experimental)

`POST /api/v1/analyses` accepts `{ "text": "...", "enableLlm": false }`. Set `enableLlm` and `aiConsent` both to `true` only after the user has consented to provider processing. Clients should redact and review sensitive data before transmission; the API also applies best-effort server-side redaction. Text is not persisted. Results include a random request-scoped `analysisId`, `schemaVersion`, decision, signals, a grounded action graph, recommendations, uncertainty and engine metadata. The `result` field retains the existing detailed response. Graph spans use UTF-16 offsets into `result.sanitizedText` and first-match semantics; they do not prove interpretation or identity.

Errors use `{ "schemaVersion": "1.0", "error": { "code": "ANALYSIS_REQUEST_FAILED", "message": "..." } }`; invalid bearer credentials use `INVALID_KEY`. Successful and failed responses are not cached. `GET /api/v1/health` reports basic process health; `GET /api/v1/capabilities` reports feature types, not provider availability. Analyses are not stored and retrieval and feedback are not implemented. There is no public rate limiter; do not expose AI publicly without external protection and budgets.

On an explicitly configured local development server only, a signed-in user can create a project-scoped test key. Pass it as `Authorization: Bearer <key>`, send a fresh UUID in `Idempotency-Key`, and set `enableLlm` explicitly to a boolean. A successful request deducts one test credit; AI failure or unavailability returns the rules fallback without deduction. Reusing a request key returns HTTP 409 instead of replaying a stored result. Revoked or expired keys return 401. The server stores a hash and prefix, not the full key. This is a local experiment: API keys and metering are disabled in production, and it is not a commercial authentication or billing system. Unauthenticated calls retain the existing guest behavior and are not metered.

```sh
curl -X POST http://127.0.0.1:3005/api/v1/analyses \
  -H 'Content-Type: application/json' \
  --data '{"text":"Ahoj mami, mam nove cislo. Posli mi ihned penize.","enableLlm":false}'
```

The current machine-readable contract is [openapi.yaml](openapi.yaml).
